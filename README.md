## Правила, согласованные с пользователем

- ИД не зависит от рабочей документации: «что смонтировано, то и запроектировано». Всё — **согласно ИД** (схемы и КЖ проектировщика в томе ИД).
- Смотреть только на фактические списки материалов; закупки не сверять, «подвохов» не искать.
- Только официальные документы о качестве (техописание ОГНЕЗА-ВГ исключено).
- СРО ИП Белоноговой в актах **не заполняется** (требование стройконтроля).
- Даты условные, важна логика: гильзы → кабеленесущие → прокладка → герметизация → оборудование → испытания.
- Гофра везде «Промрукав Строитель» (DKC игнорировать); КИС не применялся.
- Марка кабеля — по последней сводной спецификации (xlsx).
- Дубли сертификатов между АБК и КПП в перечнях «что найти» не повторять.
- Тома ИД: **отдельно по зданиям**, внутри — **5 систем** (итого 10 томов).

## Требования заказчика (из транскрипции аудио 27.10.2026)

1. **Гильзы и герметизация — один акт** («Монтаж и герметизация гильз в перекрытии/стенах»), изготовление гильз отдельно не пишется.
2. **П.1 — только наименование работ**, без материалов. Материалы и документы (сертификаты, паспорта, отказные письма) — в п.3.
3. **Кабеленесущие системы (лотки, кабель-каналы) — отдельный акт** до прокладки кабеля. Гофра — материалом в акте на прокладку.
4. **Прокладка кабеля — отдельный акт.**
5. **Акт о смонтированном оборудовании** с ведомостью в приложении.
6. **П.3 → реестр** документов о качестве (даже если документов < 5). Реестр подписывают только исполнитель и Белоногов → замена документа без переподписания акта.
7. Далее: индивидуальные испытания 72 ч (даты разнесены), техотчёт (дата = окончание испытаний), протоколы — приложением к техотчёту; акт окончания ПНР (комиссия, период, перечень оборудования, готовность к комплексному опробованию).
8. Проходки на схеме: разные УГО для перекрытия и стены, экспликация, узлы, привязка в осях и отметки — это на ИД (ИД КПП согласована).
